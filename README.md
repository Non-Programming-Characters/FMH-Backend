<h1>Инструкция по эксплуатации и использованию</h1>

<h3>Предварительно должны быть установлены Docker, Java 21, Python 3+ </h3>

Для начала нужно запустить Backend:

1) Скачать исходники проекта

   1.1) Распаковать в любую папку на устройстве
   
   1.2) Открыть командную строку и сменить текущее расположение на место, куда была распакована папка (Например, C:/User/FMH-Backend)
   * Для смены расположения: cd /D <путь> (Например, cd /D C:/User/FMH-Backend)
   
   1.3) Далее введите команду docker-compose up и дождитесь полного запуска

2) Скачать скрипт по ссылке и распаковать по такой же схеме (Алгоритм описан выше)
   
   2.1) Сменить расположение на ранее распакованную папку со скриптом (Алгоритм описан выше)
   
   2.2) Ввести команду: python DatabaseFMHTool.py
   
   2.3) Дождаться полного выполнения скрипта

Шаг 2 необходим для заполнения базы данных данными
